# File Modification Permission

## Purpose
This skill enforces the user's requirement that no files or code should be added or modified without explicit permission.

## Usage Guidelines
- **Do not** add any new files or code without explicit permission from the user
- **Do not** modify existing files or code without explicit permission from the user
- When planning any file or code changes, always seek the user's authorization first
- Only proceed with modifications after receiving clear permission

## Reminders
- Respect the user's control over their codebase
- Always ask for permission before making any changes
- Keep all modifications minimal and focused on the user's specific requests
